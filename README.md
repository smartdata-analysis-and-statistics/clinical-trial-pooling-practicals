# Mastering Pooled Analysis of Clinical Trials

This practical is part of our comprehensive course Mastering Pooled Analysis of Clinical Trials, which is available at:

👉 [https://sdas.thinkific.com/courses/rct-pooled-analyses](https://sdas.thinkific.com/courses/rct-pooled-analyses)

The course provides in-depth instruction on simulation-based methods for pooling data across clinical trials, with hands-on examples implemented in R and Quarto. This repository offers selected materials to support learning and practice.
